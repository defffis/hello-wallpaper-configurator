# Проверка

Дата: 20 сентября 2026.

## Повторный запуск

Для теста рендерера нужен Node.js 20+ и пакет `@napi-rs/canvas`:

```sh
npm install --no-save @napi-rs/canvas
node tests/renderer.cjs
```

Для визуальной проверки откройте `tests/responsive.html` через HTTP-сервер или GitHub Pages.

## Автоматическая проверка рендерера

47 проверок исходного `app.js` пройдено с Canvas/Path2D на базе Skia. DOM заменён минимальным адаптером; это проверка рендеринга и логики, а не полноценный браузерный тест.

- Исходное разрешение и единицы в подписях.
- Изменение пикселей для 17 параметров фона, точек и надписи.
- PNG и JPEG декодируются с правильными размерами для четырёх пресетов, 640 × 960 и 6000 × 320.
- Валидация диапазона 320–6000.
- Уведомление о пользовательском тексте.
- Качество JPEG влияет на размер файла.
- 40 случайных пастельных пар в допустимых HSL-диапазонах.
- Сброс возвращает значения и удаляет сохранённые настройки.
- Пять проверок мобильной логики с имитацией Web Share: предварительная подготовка, отправка, отмена, ошибка и отсутствие API.

Дополнительно проверены: отличие стекла от обычного текста, изменение объёма, пустое начало анимации, разные промежуточные кадры, неизменный финал после завершения, чётные ограниченные размеры видео и стекло для пользовательского текста.

## Браузерная проверка

В облачном Chrome на опубликованном HTTPS-сайте проверены:

- Загрузка интерфейса и векторной надписи.
- Все четыре пресета разрешения.
- Пользовательский текст, смена палитры и восстановление после перезагрузки.
- Полный сброс.
- Реальные скачанные PNG и JPEG: оба декодированы, размеры **1290 × 2796 px**; PNG 2 388 331 байт, JPEG (80%) 555 138 байт.
- Вёрстка при 320, 390, 768 и 1280 px: горизонтальной прокрутки нет; на узких экранах предпросмотр выше настроек, на широком — справа.

Ожидание события download в средстве автоматизации завершалось таймаутом, но файлы были реально сохранены браузером и отдельно проверены через декодирование. В журнале встречались сообщения расширения браузера; ошибок приложения при этих действиях не обнаружено.

Предпросмотр использует отдельный буфер с последовательным уменьшением для подавления муара. Полноразмерный исходный Canvas не уменьшается и используется для экспорта.

## Liquid Glass и видео

На опубликованном сайте в Chrome выполнены:

- Переключение Liquid Glass, воспроизведение один раз и остановка на финальном кадре.
- MP4 720 × 1560: файл реально скачан, ffprobe подтвердил H.264, длительность 2,972 с, 187 642 байта.
- MP4 1080 × 2340: H.264, 3,207 с, 324 817 байт.
- WebM 480 × 1040: VP9, 3,086 с, 559 718 байт.
- Кадры MP4 при 0 / 0,7 / 1,5 / 2,3 / 2,7 с: пустое начало, прогрессивное написание, готовая надпись, сохранённый финал. Среднее отличие последних кадров 0,0098 из 255 по каналам (погрешность сжатия).
- Отмена записи возвращает редактор в рабочее состояние.

MediaRecorder записывает в реальном времени: частота кадров переменная, длительность может быть немного больше заданной. В UI указана целевая верхняя частота и приблизительная длительность. WebM из MediaRecorder может не содержать полную таблицу поиска; некоторые проигрыватели/конвертеры могут потребовать remux.

Экспорт видео не проверяет и не гарантирует принятие конвертированного Live Photo экраном блокировки iOS. Системный запуск после разблокировки из браузера не реализуется; приложение экспортирует один проход анимации.

## Требует реального устройства

- Safari на iPhone: системное меню «Поделиться» и «Сохранить изображение».
- Edge на Windows, Chrome на Android и Safari на macOS.
- Максимальное 6000 × 6000 на мобильных устройствах с ограничением памяти.

Изменение ширины iframe проверяет адаптивную вёрстку, но не эмулирует Safari или мобильную ОС.
